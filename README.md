# EZTranscript

EZTranscript is a Chrome extension that copies a clean YouTube transcript to your clipboard with one click.

## What it does

When you click **Copy Transcript**, EZTranscript automatically:

1. Expands the video description.
2. Clicks **Show transcript**.
3. Extracts the complete transcript.
4. Removes timestamps, sound annotations, and unnecessary formatting.
5. Copies the cleaned text to your clipboard.

Everything runs locally in your browser. The transcript is not summarized or rewritten.

## Installation

EZTranscript is not yet available on the Chrome Web Store, so it must be installed manually:

1. Download or clone this repository.
2. Open `chrome://extensions` in Chrome.
3. Enable **Developer mode**.
4. Click **Load unpacked**.
5. Select the EZTranscript folder.
6. Pin EZTranscript to your browser toolbar.

## Usage

1. Open a YouTube video that has a transcript.
2. Click the EZTranscript extension icon.
3. Click **Copy Transcript**.
4. Paste the transcript wherever you need it.

## Notes

- The video must have a transcript available.
- Auto-generated YouTube transcripts are supported.
- Spoken wording is preserved, including filler words and transcription errors.
